# CSS Neon Glow Hover Effect ✨

A simple and modern web design project featuring an interactive neon glow hover effect using HTML and CSS.

## ✨ Features
- Clean and minimal black background.
- Centered dark-colored box.
- Colorful neon glow effect on hover.
- Smooth CSS transitions.
- Responsive and modern design.
- Attractive multi-color glowing border effect.

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🎨 Preview
- **Before Hover:** A simple dark box with a subtle shadow.
- **After Hover:** A beautiful multi-color neon glow appears around the box.

## 📚 Learning Purpose
This project demonstrates CSS hover effects, transitions, box-shadow, and modern UI styling.
